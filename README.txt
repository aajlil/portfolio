# Portfolio Ayman AJLIL

Portfolio personnel réalisé en HTML, CSS et JavaScript.

## Fichiers

- `index.html` : contenu du portfolio
- `style.css` : mise en page et responsive
- `script.js` : menu mobile

## Lancer le portfolio

Ouvrir simplement `index.html` dans un navigateur.

## À personnaliser

- Ajouter les captures d'écran des projets.
- Ajouter les liens GitHub des projets.
- Remplacer le lien LinkedIn si nécessaire.
- Ajouter un CV PDF dans le dossier si souhaité.
